# Пак рекламы для мониторов вагонов (пример) + пошаговый гайд

Это **готовый рабочий пример** дополнительного пака рекламы для мониторов в вагонах
Metrostroi (система «Media Display» из аддона `screen_addon`). Внутри —
три статичные картинки и **одна настоящая анимация**: один много-кадровый
файл `.vtf`, кадры крутит сам движок, нагрузка на сервер и клиент — почти ноль.

Аддон можно использовать двумя способами:

1. **Просто установить** — у администратора появится ещё один пак в меню выбора рекламы;
2. **Взять за образец** — и по гайду ниже собрать свой пак со своими картинками.

Требуется аддон мониторов (`screen_addon`). Технические детали формата — в
[docs/screen_addon_reference.md](docs/screen_addon_reference.md).

---

## 1. Установка (для тех, кто просто хочет посмотреть)

### Вариант А — папка аддонов (legacy)

1. Скачай содержимое репозитория (кнопка **Code → Download ZIP**).
2. Распакуй; папка после распаковки называется `gmod-ms-screen-pack-example-main` —
   переименуй её в `ms_screen_pack_example` и положи в `garrysmod/addons/`:

   ```
   garrysmod/addons/ms_screen_pack_example/
   ├── addon.json
   ├── lua/autorun/msd_pack_example_register.lua
   └── materials/ms_screen_packs/example/...
   ```

3. Перезапусти карту (или перезапусти игру).

### Вариант Б — Workshop

Загрузи аддон в Workshop (раздел 2, шаг 6) и подпишись на него — либо просто
заходи на сервер, где пак установлен: **сервер сам раздаёт файлы пака
подключающимся игрокам**, подписка клиента не обязательна.

### Как включить пак (только админ!)

Менять рекламу на мониторах могут **только администраторы** (или консоль
сервера) — сервер проверяет это сам, у обычных игроков интерфейс только для
просмотра:

1. Открой меню **Q → Утилиты**.
2. Категория **«Экраны вагонов (Media Display)» → «Реклама на экранах»**.
3. Отметь галочками один или сразу несколько паков (например,
   «Стандартный (встроенные)» + «Пример пака» — реклама будет крутиться из
   обоих) и нажми **«Применить»**.
4. Мониторы в вагонах начнут показывать `advert_1…3` и анимацию `anim_demo`.

Консольные команды (тоже только для админов):

```
msd_listpacks            -- показывает все паки и что выбрано
msd_setpack example      -- выбрать один пак
msd_setpack default,example  -- выбрать несколько через запятую
```

## 2. Гайд: как сделать свой пак с нуля

Итоговая структура аддона-пака:

```
папка_аддона/
├── addon.json
├── lua/
│   └── autorun/
│       └── msd_pack_<id>_register.lua      <-- регистрация (lua НЕ в materials!)
└── materials/
    └── ms_screen_packs/
        └── <id>/                           <-- id пака, латиница без пробелов
            ├── advert_1.vmt                <-- статичная реклама (описание)
            ├── advert_1.vtf                <-- статичная реклама (картинка)
            ├── advert_2.vmt / .vtf
            ├── ...
            └── my_anim.vmt / .vtf          <-- анимация (ОДИН файл на кадры)
```

### Шаг 1. Подготовь картинки

- Формат исходников — **PNG** (можно JPG), без прозрачности (альфа нужна только
  по особой надобности, тогда формат DXT5).
- Размер — **степень двойки**: отлично подойдёт **512×256** (как в примере) или
  **1024×512**. Форма не критична — движок растянет на область экрана, но
  кадры одной анимации должны быть ИДЕНТИЧНЫ по размеру.
- Хорошее правило: тёмный/контрастный дизайн читается издалека.

### Шаг 2. Конвертация PNG → VTF

Нужна утилита **VTFEdit** (Windows) либо плагин VTF для GIMP/Photoshop.
В VTFEdit порядок такой:

**Статичная картинка:**
1. `File → Import…` — выбери свой PNG.
2. В окне импорта выставь **Normal Format → DXT1** (если картинка без
   прозрачности; **DXT5** — если нужна альфа).
3. Сними галочку/режим **Generate Mipmaps** (мипмапы на маленьком экране не
   нужны, они только раздуют файл).
4. `File → Save As…` — сохрани как `advert_1.vtf`.

> DXT1/DXT5 — самый оптимизированный формат: картинка 512×256 сжимается до
> ~64 КБ вместо 512 КБ несжатой, так что пачка картинок и даже ролик из
> нескольких десятков кадров занимает мегабайты, а не гигабайты.

**Анимация (один файл-текстура!):**
1. Подготовь кадры: `frame01.png, frame02.png, …` — одинаковый размер.
2. В VTFEdit `File → Import…` выдели **сразу все кадры** (Ctrl+клик) — они
   импортируются как кадры одной текстуры.
3. Формат **DXT1**, мипмапы — выкл., сохраняй как `my_anim.vtf`.
4. Внизу окна VTFEdit будет видно число кадров (в нашем примере — `8 frames`).

### Шаг 3. Создай VMT-файл

`.vmt` — это простой текстовый файл. Скопируй и поменяй только путь.

**Статичная реклама — `advert_1.vmt`:**

```
"UnlitGeneric"
{
	$basetexture ms_screen_packs/<id>/advert_1
	$nolod 1
	$ignorez 1
	$vertexcolor 1
	$vertexalpha 1
}
```

> `$basetexture` — путь **без `materials/` и без `.vtf`** на конце.

**Анимация — `my_anim.vmt`:** то же самое + блок `Proxies`, который заставляет
движок крутить кадры ровно с нужным fps:

```
"UnlitGeneric"
{
	$basetexture ms_screen_packs/<id>/my_anim
	$nolod 1
	$ignorez 1
	$vertexcolor 1
	$vertexalpha 1
	"Proxies"
	{
		"AnimatedTexture"
		{
			"animatedTextureVar"			"$basetexture"
			"animatedTextureFrameNumVar"	"$frame"
			"animatedTextureFrameRate"		"8"
		}
	}
}
```

`animatedTextureFrameRate` = скорость кадров. Если хочешь, чтобы ролик из
8 кадров шел за 4 секунды, ставь `2` (или 8 кадров за секунду — `8`).

### Шаг 4. Зарегистрируй пак (Lua-файл)

Создай в аддоне файл `lua/autorun/msd_pack_<id>_register.lua`:

```lua
-- Регистрация пака <id>. Файл кладём в lua/autorun/, НЕ в materials!
local DESC = "Описание для меню."

local ANIMS = {
	-- имя анимации (имя .vmt-файла без расширения) → параметры показа
	-- hold = пауза ПОСЛЕ проигрывания ролика, в секундах (0 = сразу следующая)
	-- fps можно не указывать — возьмётся из animatedTextureFrameRate в .vmt
	["my_anim"] = { hold = 1 },
}

-- Запасной список реклам (план Б для Workshop): обычно система сама сканирует
-- файлы, но если по какой-то причине файлы абсолютно не видны, список выручает.
local ADS = {
	"advert_1", "advert_2",                     -- статики (имя .vmt без расширения)
	{ base = "my_anim", anim = true, frames = 8 },  -- анимация: frames = число кадров в .vtf
}

local function register()
	if MSD_Packs then
		MSD_Packs.RegisterPack("<id>", "Название в меню", DESC, ANIMS, ADS)
	else
		-- библиотека мониторов ещё не загрузилась — оставим заявку,
		-- она применится сама после загрузки sh_tvscreens_packs.lua
		MSD_Packs_Pending = MSD_Packs_Pending or {}
		table.insert(MSD_Packs_Pending, {
			id = "<id>", name = "Название в меню", desc = DESC,
			opts = ANIMS, ads = ADS,
		})
	end
end

register()
```

Важно: `id` в регистрации, имя папки `materials/ms_screen_packs/<id>/` и
`<id>` в путях VMT — **три одинаковых слова**.

### Шаг 5. Проверь результат

1. Перезапусти карту.
2. `Q → Утилиты → Экраны вагонов → Реклама на экранах` — твой пак должен быть
   в списке с числом реклам (статиков + 1 анимация-папка считаются отдельно).
3. Воспользуйся `msd_listpacks` в консоли, если список выглядит странно.

### Шаг 6. Публикация в Workshop (по желанию)

1. Открой `addon.json` и поправь `title` / `type` / `tags` на свои.
2. Запакуй:

   ```
   "C:\Program Files (x86)\Steam\steamapps\common\GarrysMod\bin\gmad.exe"
       create
       -folder "C:\...\gmod-ms-screen-pack-example"
       -out    "C:\...\my_gma_pack.gma"
   ```

3. Залей GMA в Workshop любой удобной утилитой (обычно **gmpublisher** — она
   удобная и работает с GUI) — либо любым другим загрузчиком Workshop.

Работает из Workshop? Да — система ищет файлы паков несколькими путями поиска
(THIRDPARTY → GAME → WORKSHOP), а список реклам на чёрный случай можно
задать таблицей `ads` (план Б, см. отдельную секцию «## Workshop» в
`docs/screen_addon_reference.md`).

## 3. Где устанавливать пак

| Установка              | Что получится |
|---|---|
| Пак только на **сервере** (legacy или Workshop) | Достаточно! Файлы пака **сами** ставятся на раздачу (`resource.AddFile`) и скачиваются клиентами при подключении. До скачивания на экране будет пустота. |
| Пак и на сервере, и у клиента | Тоже ок — файлы уже на месте, никого ждать не нужно. |
| Пак только у клиента, не на сервере | Не работает: сервер не знает о паке и не предложит его в списке. |

## 4. Частые проблемы

| Симптом | Причина / решение |
|---|---|
| Экраны чёрные вместо рекламы | Файлы ещё скачиваются (подожди); пак не установлен у того, кто смотрит; на мониторе нет аддона экранов. |
| Пака нет в списке | Не загружен файл регистрации (`lua/autorun/...`), не та папка (`ms_screen_packs/<id>/` — иначе id), или в папке нет ни одного `.vmt`. |
| В списке 0 реклам, хотя пак появился | Скан не нашёл ни одного `.vmt`. Файлы должны лежать в `materials/ms_screen_packs/<id>/` (подпапки пакета тоже просматриваются, глубина — до 4 уровней). |
| Анимация чёрная / «checkerboard» | Прокси в `.vmt` с опечаткой, или VTF не много-кадровый (файл должен содержать ≥ 2 кадров), или у кадров разный размер. |
| Анимация выглядит, будто крутится дважды | Так и должно: прокси движка **зациклен** — если во время `hold`-паузы ролик проходит повторный круг, используй `hold = 0` в регистрации для строгой однократности. |
| Может ли рекламу сменить не-админ | Нет. Права (`IsAdmin`/`IsSuperAdmin`) проверяются **на сервере** и в меню (сетевое сообщение), и в консольной команде `msd_setpack` — левый вызов отклоняется с сообщением «менять рекламу могут только администраторы». `msd_listpacks` доступен всем, но это только чтение списка. |

## 5. Внутри этого примера

```
materials/ms_screen_packs/example/
├── advert_1.vmt|.vtf   3 статичные картинки (512×256, DXT1, ~64 КБ)
├── advert_2.vmt|.vtf
├── advert_3.vmt|.vtf
└── anim_demo.vmt|.vtf  анимация: ОДИН VTF, 8 кадров, прокси AnimatedTexture
lua/autorun/msd_pack_example_register.lua   регистрация с планом Б (ads)
addon.json                                  заголовок для Workshop (gmad)
PAKI_README.md                              краткое описание этого примера
docs/screen_addon_reference.md              полная документация системы паков
```
