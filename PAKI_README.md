# Пример аддона-пака рекламы для мониторов вагонов

Это **штатный демонстрационный пак** для системы рекламы, встроенной в аддон
экранов (`screen_addon`). Весь пак собран в самом оптимизированном формате —
**DXT1** (сжатые текстуры, 64 КБ на картинку 512x256 вместо 512 КБ несжатой).

Что здесь лежит:

- `materials/ms_screen_packs/example/advert_1..3.vmt|.vtf` — три **статичных**
  рекламы (DXT1);
- `materials/ms_screen_packs/example/anim_demo.vmt|.vtf` — **анимированная**
  реклама: это **один файл**-текстура с 8 кадрами (DXT1), в `.vmt` прописан
  прокси `AnimatedTexture` — кадры крутит **сам движок**, нагрузки на сервер
  и клиент нет. Показ длится `кадры / fps` + пауза 1 с, затем смена рекламы
  (fps читается из `.vmt`, при желании переопределяется в регистрации);
- `lua/autorun/msd_pack_example_register.lua` — регистрация имени пака
  («Пример пака») и настроек анимации (`fps`/`hold`) для меню Утилит;
- `addon.json` — описание аддона для конвертации в workshop.

## Быстрый старт

1. Установи этот аддон (папка `ms_screen_pack_example` в `garrysmod/addons/`)
   рядом с аддоном `screen_addon`. Достаточно поставить его **только на
   сервер** — сервер сам раздаст текстуры подключающимся игрокам.
2. Зайди на сервер, в меню `Q → Утилиты → Экраны вагонов (Media Display) →
   Реклама на экранах` отметь один или несколько паков и нажми «Применить».
   Например, можно отметить и «Стандартный (встроенные)», и «Пример пака» —
   реклама будет крутиться из обоих.
3. Мониторы в вагонах начнут крутить `advert_1..3` и анимацию `anim_demo`.

Возвращение только стандартных картинок из аддона экранов — выбор одного пака
«Стандартный (встроенные)» (`default`).

## Как сделать свой пак

Скопируй этот аддон, переименуй папку пака (`materials/ms_screen_packs/example`
→ `materials/ms_screen_packs/<твой_id>`), положи свои `.vtf`/`.vmt` (рекомендуется
DXT1) и анимации — одной много-кадровой текстурой с прокси `AnimatedTexture`
(или папкой с пронумерованными кадрами), измени регистрацию в `lua/autorun/…`.
Полная инструкция (формат, DXT, анимации, мультивыбор) — в `PAKI_README.md`
корня аддона `screen_addon`.
